# Contributing to MultiTenant ETL

Thank you for your interest in contributing to MultiTenant ETL! We welcome contributions from the community.

## How to Contribute

### Reporting Issues

- Use the issue templates to report bugs or request features.
- Provide as much detail as possible, including steps to reproduce for bugs.
- Check existing issues to avoid duplicates.

### Submitting Pull Requests

1. Fork the repository.
2. Create a feature branch from `main`.
3. Make your changes.
4. Write tests for new functionality.
5. Ensure all tests pass.
6. Update documentation if necessary.
7. Submit a pull request with a clear description.

### Code Style

- Follow the existing code style and conventions.
- Use meaningful variable and function names.
- Write clear, concise comments.
- Ensure code is well-tested.

### Testing

- Run the test suite before submitting changes.
- Add unit tests for new features.
- Integration tests should be added for API changes.

### Documentation

- Update README.md or relevant docs for significant changes.
- Use clear, concise language.

## Code of Conduct

Please adhere to our [Code of Conduct](CODE_OF_CONDUCT.md) in all interactions.
