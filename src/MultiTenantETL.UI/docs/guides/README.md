2. Review [OAuth PKCE](oauth-pkce.md) to understand authentication
3. Check [Configuration Constants](configuration-constants.md) for configuration management
4. Use [Quick Start](quick-start.md) for examples of using roles and permissions
5. Refer to [Troubleshooting](troubleshooting.md) when you encounter issues
